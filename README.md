# Jesus Words — Android

The Android version of the **Jesus Words** iOS app: daily Bible verses in English and Tamil.

Everything needed to build it is in [`JesusWords_Android_Handoff/`](JesusWords_Android_Handoff/):

- **[`START_HERE.md`](JesusWords_Android_Handoff/START_HERE.md)** — the message to give a new AI coding chat
- **[`ANDROID_BUILD_BRIEF.md`](JesusWords_Android_Handoff/ANDROID_BUILD_BRIEF.md)** — the full app specification
- `data/` — all 365 verses (English + Tamil), themes, wallpapers, UI text
- `assets/` — backgrounds, widget images, tip artwork, app icon (WebP)
- `ios_reference_source/` — the original SwiftUI source of the iOS app
